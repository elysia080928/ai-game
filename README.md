# 机偶回路 · MVP

单人肉鸽卡牌 + 视觉小说的最小可玩版本。固定六节点地图：**战斗 1 →（招募 / 旧型号信号 / 爱的中继站）→（废弃维修站 / 校准平台 / 维修无人机群）→（漂流卡匣 / 记忆回收站）→（断线商船 / 观测塔 / 失控训练场）→ 战斗 2 → 完成画面**，共 13 个节点，每趟冒险走 6 个。

- 前端：原生 HTML / CSS / JavaScript（`static/`）
- 后端：Python + FastAPI（`app/`），战斗、金币、招募、奇遇、剧情与存档都由服务端结算
- 数据：SQLite 保存账号与存档；卡牌、敌人、遭遇、节点与剧情在 `content/game.json`

## 本地运行

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

打开 <http://127.0.0.1:8000>，注册账号即可开始。数据库默认写入 `data/game.db`（已被 `.gitignore` 忽略）。

## Docker

```bash
docker build -t ai-game-mvp .
docker run -p 7860:7860 -v $(pwd)/data:/app/data ai-game-mvp
```

镜像默认监听 `PORT=7860`（可用环境变量覆盖），数据目录为 `DATA_DIR=/app/data`。

## 部署到魔搭创空间

- 端口按平台要求使用 7860；启动命令由 Dockerfile 提供。
- 必须把 `/app/data` 挂到平台提供的持久化目录；平台若不提供持久化卷，容器重启或重新部署后账号与存档可能丢失。部署前需要在平台上核实容器文件系统与卷的实际行为，本仓库不做持久性保证。
- 平台提供 HTTPS 时设置 `COOKIE_SECURE=1`，让会话 Cookie 只走加密连接。

## MVP 规则要点

- 双方 4 列、领袖 15 生命；玩家结束后从左到右攻击，敌方按预告计划部署并攻击。
- 敌方预告直接显示在四列上，标出本回合/下回合、名称、攻击与生命；同列多条计划分别列出，计划结束后清空。
- 单位可带特殊机制：宽体单位占 2 个相邻列（双轨机偶、宽幅壁垒），部署时两列都必须为空，回收或死亡同时释放两列；分叉攻击在当前列之外再打右侧列（单格）或自身占据的两列（宽体）；双击对同列结算两次，第一次击杀后第二次转打领袖；飞行单位攻击时绕过没有 `reach` 的防守者直击领袖，没有 `reach` 的单位也无法伤害飞行防守者；`reach` 单位可以攻击飞行单位。敌方预告会标出宽度与攻击模式。
- 首回合 4 能量，之后每回合 +2 且可保留；回收返还 `max(1, 实际支付 // 2)`。
- 起手 6 张（≥4 张费用≤2、≥1 张低费单位），之后每回合抽 2 张；6 费牌第 3 回合起可抽；牌堆耗尽不洗回。
- 手牌超过 10 张时先抽完，再由玩家选择弃牌；单场每张卡只能使用一次。
- 战斗 1 胜利 +20 金币；战斗 2 不发金币。招募固定报价、最多购买一次；可购买新单位或升级已有同名单位（不增加张数）。
- 信号奇遇“旧型号信号”：一张已有单位最大生命 +1，或未满级单位升 1 级并保留已有改造，也可离开。
- 维修奇遇“废弃维修站”：一张已有单位攻击 +1 或最大生命 +2，先预览再确认，也可离开；两类生命加成可叠加，攻击与生命改造分别记录。每个节点只能结算一次，强化保留到本趟冒险结束。
- 校准平台：三选一，攻击 +1、最大生命 +2 或等级 +1（满级不可选），同样先预览再确认；与维修站互斥。
- 记忆回收站：拆解一张卡牌换取金币，价格为 `5 × 当前费用 + 5 × (等级 - 1)`；不能移除最后一张单位牌，也不能清空牌组。与漂流卡匣互斥。
- 漂流卡匣：固定展示 3 张候选，只能带走一张；已有卡升 1 级，未拥有卡加入牌组（受 20 张上限约束）。候选由本节点种子确定，可花 10 金币重抽一次。与记忆回收站互斥。
- 断线商船：固定三件商品（新单位 / 已有单位升级 / 属性强化），价格由服务端配置；每个节点最多购买一件，也可离开。已拥有、满级、牌组已满或金币不足时显示不可用原因。
- 观测塔：由节点种子从三个试炼中抽取两个；选定一个后立即判定，成功可在三张奖励卡中选一张（已有卡升级、新卡入组），失败可领取 5 金币或离开。与断线商船、失控训练场互斥。
- 爱的中继站：保留信号会写入持久剧情标记 `relay_kept`，不立即获得强化；切断回路则选择一张已有单位攻击 +1。选择后进入后置剧情，后续对白按标记变化。与招募、信号互斥。
- 维修无人机群：三选一：已有单位攻击 +1、最大生命 +1，或下一场战斗起手抽牌 +1。前两种需指定单位，抽牌强化写入 `pendingDrawBonus`，只作用于下一场战斗；先预览再确认，也可离开。与废弃维修站、校准平台互斥。
- 失控训练场：通常二选一，保留中继信号后额外解锁「信号同步」。过载演算让下一场战斗首回合 1 列额外出现突击哨兵，获胜奖励 14 金币；低功率演算让下一场战斗首回合能量 -1，获胜奖励 8 金币；信号同步让首回合 1 列额外出现突击哨兵，获胜奖励 18 金币，但仅当存档含 `relay_kept` 时可见和可选。挑战写入存档 `pendingChallenges`，只挂载下一场战斗；战斗失败重试仍保留，确认胜利时结算奖励并清空，不能重复领取。与断线商船、观测塔互斥。
- 选关分四层：补给（招募 / 旧型号信号 / 爱的中继站）、维修（废弃维修站 / 校准平台 / 维修无人机群）、回收（漂流卡匣 / 记忆回收站）、经济（断线商船 / 观测塔 / 失控训练场）；每层只能进入一个节点，未选支线显示为关闭。选关只允许进入当前可用节点，已完成节点不能重玩。刷新或重新登录会回到选关阶段，旧版线性/字符串路线存档会迁移为按分支组保存的路线；未知或高于当前程序版本的存档会被拒绝读取，数据库原记录保持不变。
- 单位牌拖到己方空列部署；宽体单位拖到可容纳两列的起点时同时高亮两列，只扣一次费用。选中单位牌后也可用键盘聚焦空列并按 Enter/空格部署。鼠标点击卡牌再点空列不会部署，会提示改用拖动。紧急维修拖到受伤的己方单位，闪电脉冲拖到敌方单位。占用列、错误目标、能量不足及战斗结束等情况不改变手牌和能量并给出提示；拖动时不会选中文字。
- 选关界面为左右对页的展开书页，包含中缝、纸页边缘、可进入节点与图例；窄窗自动堆叠为上下页。剧情立绘优先使用配置图片，缺失时显示内置机械剪影。
- 剧情支持配置化背景、选项、标记与条件台词；每节点的前后剧情可为空。逐句推进；跳过本段会在待选选项前停下，不会自动选择。
