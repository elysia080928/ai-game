# 若你坠入记忆之海

单人肉鸽卡牌 + 视觉小说。新版冒险依次经过 10/15/15 层的三张分支地图；第二、三张地图各有 4 场中段战斗、4 个奇遇层、精英分支和终点战，第三张地图以海底背景呈现。新增层为“机偶补给站”，免费进行两轮三选一。地图类型、种子、完整路线与遭遇写入存档，刷新、重登和战斗重试都不会重抽；进行中的战斗也写入数据库，刷新或服务重启后继续同一场战斗。旧版固定地图继续使用 8/12/12 层、20 张牌组上限和旧奖励规则。

- 前端：原生 HTML / CSS / JavaScript（`static/`）
- 后端：Python + FastAPI（`app/`），战斗、金币、招募、奇遇、剧情与存档都由服务端结算
- 数据：SQLite 保存账号与存档；卡牌、敌人、遭遇、节点与剧情在 `content/game.json`

## 本地运行

Windows 用户双击 `start_game.bat` 即可启动。首次运行会在项目目录创建 `.venv` 并安装依赖，需要 Python 3.12 或更新版本以及网络连接；服务启动后会自动打开浏览器并使用空闲本地端口。再次启动时会复用已安装的依赖。关闭最小化的服务器窗口即可停止游戏。也可以手动运行：

```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

打开 <http://127.0.0.1:8000> 并登录后会进入标题菜单。可继续当前会话最近使用的存档槽，或从三个账号存档槽中选择继续、新开或删除冒险；新账号的第 1 槽预置初始冒险。首次进入开场序幕和每次新开冒险都会播放开场 CG；看过的 CG 会按账号收录到主菜单的“记忆回廊”，可查看缩略图并点击打开大图。背景音乐按菜单、剧情、奇遇、战斗和 CG 场景循环播放，主音量保存在当前浏览器。数据库默认写入项目目录中的 `data/game.db`（已被 `.gitignore` 忽略），无论从哪个工作目录启动都不会写到项目目录之外。

## 测试

```bash
python tests/test_rules.py
python tests/test_save_version.py
python tests/balance_sim.py        # 200 组固定种子/章节/类别，四类牌组 × 三种策略
```

规则测试共 93 项，覆盖战斗、三张地图、剧情、教学、新版成长（含商店同名卡逐实体升级可用性）、第三章篝火 CG、最终 Boss CG 与旧存档兼容。存档/API 测试还验证 v1 单存档与战斗状态迁移到第 1 槽、数据库版本迁移、CG 画廊解锁与旧档补发、未知未来版本保护、覆盖确认、会话选槽隔离、删除槽及其战斗进度、过期版本写入冲突、过期会话拒绝访问，以及战败后重置战斗清理补给挑战。

平衡自检直接调用实际战斗函数，固定种子、不复制规则。每章、每类遭遇（普通/精英/Boss）各跑 200 局，分别报告四类牌组（免费、成长、删牌、集中强化）和三种简单策略（基础部署、防守优先、主动回收）；输出胜率、回合数、部署量、领袖伤害、敌方储备和卡手指标。当前结果显示普通战胜率 75%–100%（三种策略合计），精英战 32%–100%，Boss 战 1%–99.5%，牌组结构与策略差异明显；“主动回收”常主动牺牲场面，胜率低是策略本身的行为，不与前两种策略平均。该模拟只验证自动策略下的数值压力，**不代表真人通关率，真人难度尚未验证**。

启动一个测试端口的服务后还可以运行端到端测试：

```bash
python -m uvicorn app.main:app --port 8099
BASE_URL=http://127.0.0.1:8099 python tests/e2e_smoke.py     # API 三张地图完整路线：遭遇预告、分支关闭、精英三选一、重登不重抽、章节自动衔接、存档恢复、账号隔离与完成画面
BASE_URL=http://127.0.0.1:8099 node tests/ui_smoke.js        # 无头 Chromium：标题菜单、三槽存档覆盖/删除、开场 CG、CG 画廊缩略图与大图预览、场景音乐和音量保存、教程/战斗/地图流程与刷新恢复、桌面/窄窗/手机布局
```

UI 测试默认查找 Windows Edge；可用 `BROWSER_PATH`、`EDGE_PATH` 或 `CHROME_PATH` 指定其他 Chromium 浏览器路径。设置 `TUTORIAL_UI_ONLY=1` 可运行首战专项：真实鼠标拖动、各阶段推进、刷新恢复、桌面及横屏手机布局、获胜奖励和地图衔接。

## Docker

```bash
docker build -t ai-game-mvp .
docker run -p 7860:7860 -v $(pwd)/data:/app/data ai-game-mvp
```

镜像默认监听 `PORT=7860`（可用环境变量覆盖），数据目录为 `DATA_DIR=/app/data`。容器以非 root 用户（UID 10001）运行，挂载的数据目录需允许该用户写入，否则无法创建数据库。

## 部署到魔搭创空间

- 端口按平台要求使用 7860；启动命令由 Dockerfile 提供。
- 必须把 `/app/data` 挂到平台提供的持久化目录；平台若不提供持久化卷，容器重启或重新部署后账号与存档可能丢失。部署前需要在平台上核实容器文件系统与卷的实际行为，本仓库不做持久性保证。
- 请求协议为 HTTPS 时会话 Cookie 自动带 `Secure`；反向代理终止 TLS 时设置 `TRUST_PROXY=1` 以识别转发协议，也可直接设置 `COOKIE_SECURE=1` 强制启用。`TRUST_PROXY=1` 时同时读取 `X-Forwarded-For` 作为客户端地址；不要在没有可信代理时开启，否则客户端可伪造来源地址。

## MVP 规则要点

- 新冒险的第一场固定为「初次协作」：固定起手、敌人和出场列，通过实际拖动、结束回合、指令、回收与双格部署推进引导。提示不遮挡战场，可随时跳过；进度写入后端战斗存档，刷新可继续，重试恢复同一初始局面。已开始的旧冒险保留原遭遇，新开冒险体验新教程。后续战斗继续从遭遇池抽取。
- 双方 4 列、领袖 15 生命；玩家结束后从左到右攻击，敌方按预告计划部署并攻击。
- 敌方预告直接显示在四列上，标出本回合/下回合、名称、攻击与生命；同列多条计划分别列出，计划结束后清空。
- 单位可带特殊机制：宽体单位占 2 个相邻列（双轨机偶、宽幅壁垒），部署时两列都必须为空，回收或死亡同时释放两列；分叉攻击在当前列之外再打右侧列（单格）或自身占据的两列（宽体）；双击对同列结算两次，第一次击杀后第二次转打领袖；飞行单位攻击时绕过没有 `reach` 的非飞行防守者，飞行单位或 `reach` 单位可以攻击飞行防守者；地面单位没有 `reach` 时不能伤害飞行防守者。护盾在首次受到正伤害时抵消 1 点并消耗；爆裂甲虫死亡时对左右相邻敌方单位各造成 1 点伤害；雷壳虫死亡时对同列敌方单位造成 2 点伤害；轨道守卫可替相邻列友军承受一次敌方攻击；空间锚使相邻列玩家单位无法被轨道守卫拦截；漂移猎手在敌方阶段结束时向右移动 1 列，目标列被占用或已到最右列时停在原地；信号干扰器部署后使玩家下回合能量 -1，整场最多触发一次；镜像核心横扫全部场上单位，空列不伤领袖；镜像无人机部署时复制同列对位玩家单位的攻击模式。敌方预告会标出宽度、攻击模式、护盾、拦截、移动和触发效果。
- 首回合 4 能量，之后每回合 +2 且可保留；回收返还 `max(1, 实际支付 // 2)`。
- 起手 6 张（≥4 张费用≤2、≥1 张低费单位），之后每回合抽 2 张；6 费牌第 3 回合起可抽；牌堆耗尽不洗回。
- 若本回合抽牌会使手牌超过 10 张，先从现有手牌中弃掉足够数量，再抽本回合可抽的牌；单场每张卡只能使用一次。
- 前期普通战胜利 +20 金币；后期普通战、Boss 与镜像核心不发金币；精英战胜利 +30 金币。招募固定报价、最多购买一次；新版冒险购买后加入独立 1 级实体（可重复购买同名卡），旧冒险仍升级已有同名单位。
- 信号奇遇“旧型号信号”：一张已有单位最大生命 +1，或未满级单位升 1 级并保留已有改造，也可离开。
- 维修奇遇“废弃维修站”：一张已有单位攻击 +1 或最大生命 +2，先预览再确认，也可离开；两类生命加成可叠加，攻击与生命改造分别记录。每个节点只能结算一次，强化保留到本趟冒险结束。
- 校准平台：三选一，攻击 +1、最大生命 +2 或等级 +1（满级不可选），同样先预览再确认；与维修站互斥。
- 记忆回收站：拆解一张卡牌换取金币，价格为 `5 × 当前费用 + 5 × (等级 - 1)`；不能移除最后一张单位牌，也不能清空牌组。与漂流卡匣互斥。
- 漂流卡匣：固定展示 3 张候选，只能带走一张；旧冒险中已有卡升 1 级，新版冒险一律加入独立 1 级实体且不受牌组上限约束。候选由本节点种子确定，可花 10 金币重抽一次。与记忆回收站互斥。
- 断线商船：固定三件商品（新单位 / 已有单位升级 / 属性强化），价格由服务端配置；每个节点最多购买一件，也可离开。已拥有、满级、金币不足时显示不可用原因；新版冒险没有“牌组已满”。新版同名卡按当前选中的实体判断能否升级，第一张满级不会禁用另一张未满级副本；购买请求携带 `cardUid`，只修改指定实体。
- 观测塔：由节点种子从三个试炼中抽取两个；选定一个后立即判定，成功可在三张奖励卡中选一张（旧冒险升级已有卡，新版冒险加入独立 1 级实体），失败可领取 5 金币或离开。与断线商船、失控训练场互斥。
- 爱的中继站：保留信号会写入持久剧情标记 `relay_kept`，不立即获得强化；切断回路则选择一张已有单位攻击 +1。选择后进入后置剧情，后续对白按标记变化。与招募、信号互斥。
- 维修无人机群：三选一：已有单位攻击 +1、最大生命 +1，或下一场战斗起手抽牌 +1。前两种需指定单位，抽牌强化写入 `pendingDrawBonus`，只作用于下一场战斗；先预览再确认，也可离开。与废弃维修站、校准平台互斥。
- 机偶补给站：新版冒险的固定成长节点，免费进行两轮三选一；每轮可领取一张独立 1 级卡牌或放弃本轮，已领取的卡不会因下一轮放弃而撤销。第一张地图的两个补给站分别为纯补给与交换站，后两张地图另有挑战站：交换站可在两轮后支付本章金币（10/15/20）或移除一张仍满足起手保底的牌，换取一张额外候选，每站限一次；挑战站可在两轮后接受“低功率挑战”（下一场战斗首回合能量 -1）或“援军挑战”（下一场战斗 1 列出现突击哨兵，额外奖励 10 金币），胜利后获得额外三选一，首次战败则压力与奖励一并消失。接受前显示目标遭遇与计划列号，挑战奖励使用独立标题；战败后重试或重置战斗都不会恢复压力或奖励。两轮与附加候选、已领取记录和挑战状态都在进入节点时由种子确定并写入存档，刷新或重登不会重抽，重复提交不会跨轮领卡或重复结算。
- 失控训练场：通常二选一，保留中继信号后额外解锁「信号同步」。过载演算让下一场战斗首回合 1 列额外出现突击哨兵，获胜奖励 14 金币；低功率演算让下一场战斗首回合能量 -1，获胜奖励 8 金币；信号同步让首回合 1 列额外出现突击哨兵，获胜奖励 18 金币，但仅当存档含 `relay_kept` 时可见和可选。挑战写入存档 `pendingChallenges`，只挂载下一场战斗；战斗失败重试仍保留，确认胜利时结算奖励并清空，不能重复领取。与断线商船、观测塔互斥。
- 新版冒险生成 10/15/15 层的种子地图，依次为林间边境、回声长廊、静海档案。第一张为起点教学战、2 场中段普通战、2 个奇遇层、2 个机偶补给站、一个普通/精英二选一分支、后期普通战与镜像关隘；后两张各有 4 场中段普通战、4 个奇遇层、3 个机偶补给站（纯补给、交换站、挑战站各一）、一个普通/精英二选一分支与终点战。普通路线提供一场无精英奖励的普通战，精英路线风险更高，胜利给 30 金币与三选一卡牌奖励。补给站固定在全路线必经处：第一层在教学后首场普通战胜利后与终点前，后两层在入层起始战后、第三场必经普通战后与终点前；补给不相邻，终点前有免费强化机会。每层只进入一个节点，未选支线关闭；选关只允许进入当前可用节点，已完成节点不能重玩。章节衔接保留牌组、金币与剧情标记，第三张地图通关后显示最终完成页。旧冒险继续使用原 8/12/12 层地图。
- 地图类型（`map1` / `map2` / `map3`）、种子、完整路线、节点与遭遇写入存档，刷新或重新登录不会重抽；旧存档缺少地图类型时按第一张地图读取。同一趟冒险中奇遇类型最多出现一次，同一张地图内战斗遭遇不重复，同一层的分支选项名称也不重复。普通战遭遇从早期/后期两个池中抽取，预告与实际敌人一致；每个池至少 3 个选项。精英胜利在原有金币外提供三张候选卡三选一，可放弃；新版候选只从当前章节进度已开放的卡池抽取，同名卡按独立 UID 加入，牌组没有数量上限；旧冒险仍覆盖全部卡牌并受 20 张上限约束。旧版固定地图存档继续按原路线运行；未知或高于当前程序版本的存档会被拒绝读取，数据库原记录保持不变。
- 单位牌拖到己方空列部署；宽体单位拖到可容纳两列的起点时同时高亮两列，只扣一次费用。选中单位牌后也可用键盘聚焦空列并按 Enter/空格部署。鼠标点击卡牌再点空列不会部署，会提示改用拖动；触屏设备可以直接轻触空列部署。紧急维修拖到受伤的己方单位，闪电脉冲拖到敌方单位。占用列、错误目标、能量不足及战斗结束等情况不改变手牌和能量并给出提示；拖动时不会选中文字。补给站的挑战选项和交换移除目标也支持键盘 Enter/空格选择。
- 三章选关地图铺满游戏窗口，按服务端节点坐标绘制全部分支、真实连线与可进入/锁定/已完成/已关闭状态。四角放置章节题签、金币与进度、提示图例、账号与菜单，采用适配各章配色的皮革与木牌控件；窄横屏保持完整路线可见，手机竖屏提示旋转设备。剧情立绘优先使用配置图片，缺失时显示内置机械剪影。
- 剧情支持配置化背景、选项、标记与条件台词；每节点的前后剧情可为空。逐句推进；跳过本段会在待选选项前停下，不会自动选择。
